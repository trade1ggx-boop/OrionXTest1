# OrionX AI

A native Android Kotlin + Jetpack Compose foundation for the OrionX AI assistant.

## Included

- Pixel-inspired dark interface
- Home screen
- Chat screen with local demo messages
- Settings screen
- GitHub Actions APK build workflow

## Build locally

```bash
./gradlew assembleDebug
```

APK output:

```text
app/build/outputs/apk/debug/app-debug.apk
```
